# EazyTech

Курированный каталог периферии: мыши, клавиатуры, наушники, честные цены.
Чистые ES-модули, без сборщиков и библиотек — работает на любом статическом хостинге.

## Структура

```
├── index.html          главная
├── category.html       каталог (?cat=mice | keyboards | headphones)
├── device.html         страница устройства (?id=...)
├── compare.html        сравнение (?ids=a,b или через кнопку на устройстве)
├── methodology.html    методика
├── css/                base / animations / components / effects / responsive
├── js/
│   ├── core/           курсор, канвас-фон, переходы, scroll-reveal
│   ├── data/           загрузчик, фильтры
│   ├── ui/             карточки, радар, бар-чарт, сравнение
│   └── app.js          точка входа
└── data/devices/       одно устройство = один файл
```

## Как добавить устройство

1. Кидаешь новый JSON в `data/devices/` — имя файла любое, файлов сколько хочешь
   (хоть 1000 — пагинация разложит их по страницам сама).
2. Добавляешь имя файла в `data/devices/index.json`.
3. Обновляешь страницу.

Гитхаб не умеет отдавать листинг папки, поэтому скрипт читает манифест
`index.json`, а дальше тянет каждый файл из него. Битый/отсутствующий файл
просто пропускается — остальной каталог работает.

## Поля JSON

```json
{
  "id": "g102",
  "name": "Logitech G102 Lightsync",
  "brand": "Logitech",
  "category": "mice",
  "images": ["https://.../1.jpg", "https://.../2.jpg"],
  "short": "Ветеран бюджетного сегмента.",
  "description": "Параграф первый.\n\nПараграф второй.",
  "price": 1790,
  "fairPrice": 1900,
  "scores": { "community": 6900000, "personal": 6200000, "ai": 5900000 },
  "class": "budget",
  "connection": "wired",
  "mechanism": "mechanical",
  "kolhoz": false,
  "reviews": [
    { "author": "Стас", "score": 7, "date": "2026-02-15", "text": "..." }
  ],
  "specs": { "Вес": "85 г", "Сенсор": "Mercury" },
  "shops": [{ "name": "DNS", "price": 1790 }],
  "pros": ["..."],
  "cons": ["..."],
  "life": { "months": 18, "risk": 10, "riskLabel": "...", "fail": 36, "failLabel": "..." },
  "bench": { "input": 6.0, "ergo": 8.4, "materials": 6.6, "features": 5.4,
    "reliability": 6.2, "support": 7.0, "build": 6.8, "software": 6.9,
    "value": 8.7, "feel": 6.2 }
}
```

### Оценки и топы

`scores` — произвольный набор баллов в формате бенчмарков (0–10 000 000),
выставляешь сам. Стандартные ключи:

- `community` — оценка общества
- `personal` — личная оценка
- `ai` — оценка ИИ

Средний балл считается автоматически по всем ключам и показывается на карточке,
на странице устройства и в сравнении. Топ-места (ТОП 1, ТОП 2…) считаются сами:
по среднему баллу внутри категории и в общем зачёте. Бейдж на карточке — для
топ-10 категории, точное место — на странице устройства.

### Фильтры

- `category`: `mice` | `keyboards` | `headphones` — чипы над каталогом
- `class`: `budget` (Дешевка) | `value` (Топ за свои деньги) | `balanced` (Цена = качество)
- `connection`: `wired` (Проводная) | `wireless` (Беспроводная) | `hybrid` (Комбинированная)
- `mechanism`: `mechanical` (Механика) | `magnetic` (Магнитка) | `optical` | `membrane`

Панель фильтров собирается из данных: показываются только те значения,
которые реально встречаются в базе. Плюс цена, мин. балл, бренды и Fair Deal.

### Теги

Считаются автоматически: `kolhoz: true` — красный пульсирующий «Колхоз»,
`price <= fairPrice` — «Fair deal».

### Опционально

- `images` — массив ссылок; пусто или без поля — заглушка, несколько штук — галерея
- `description` — абзацы через `\n\n`, секция «Разбор»
- `reviews` — обзоры, секция «Обзоры», счётчик на карточке
- `bench` — 10 осей для радара; нет поля — секция скрывается
- `life` — таймлайн долговечности; нет поля — секция скрывается

## Пагинация

30 устройств на страницу на десктопе, 15 на мобильных. Пересчитывается при
изменении размеров окна.

## Локально

Любой статик-сервер из корня, например:

```bash
python3 -m http.server 8000
```

Данные кешируются в sessionStorage на вкладку — после правок JSON
достаточно обновить страницу в новой вкладке.

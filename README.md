# EazyTech

Курированный каталог периферии: мыши, клавиатуры, наушники, честные цены.
Светлая кремовая тема, чистые ES-модули, без сборщиков и библиотек —
работает на любом статическом хостинге.

## Структура

```
├── index.html          главная
├── category.html       каталог (?cat=mice | keyboards | headphones)
├── device.html         страница устройства (?id=...)
├── compare.html        сравнение (?ids=a,b или через кнопку на устройстве)
├── methodology.html    методика
├── css/                base / animations / components / effects / responsive
├── js/
│   ├── core/           канвас-фон, переходы, scroll-reveal
│   ├── data/           загрузчик, фильтры, настройки (валюта)
│   ├── ui/             карточки, радар, бар-чарт, сравнение
│   └── app.js          точка входа
└── data/devices/       одно устройство = один файл
```

## Как добавить устройство

1. Скопируй `data/devices/test-device.json` — это шаблон с комментариями
   по каждому полю. Переименуй как угодно.
2. Заполни своими данными. Комментарии `//` и `/* */` в JSON разрешены —
   загрузчик вырезает их перед парсингом, можно документировать прямо в файле.
3. Кинь файл в `data/devices/` — и всё. Манифест больше не нужен:
   на GitHub Pages список файлов берётся из API репозитория,
   `index.json` остался только фолбэком для локального хостинга.
   Сам `test-device.json` в каталог не попадает.
4. Обнови страницу.

Файлов может быть сколько угодно (хоть 1000) — пагинация разложит их сама:
30 устройств на страницу на десктопе, 15 на мобильных. Битый файл не роняет
каталог, просто пропускается.

## Промпт для ИИ

Внизу `data/devices/test-device.json` лежит готовый блок «PROMPT ДЛЯ ИИ».
Копируешь от маркера «НАЧАЛО» до «КОНЕЦ», отправляешь нейросети вместе
с описанием товара — она вернёт готовый JSON по схеме. Кидаешь файл
в `data/devices/` — устройство в каталоге.

## Поля JSON

```jsonc
{
  "id": "g102",                 // латиницей, без пробелов
  "name": "Logitech G102",      // название
  "brand": "Logitech",          // фильтр «Бренд»
  "category": "mice",           // mice | keyboards | headphones
  "images": ["https://.../1.jpg", "https://.../2.jpg"],
  "short": "Одна-две строки для карточки.",
  "description": "Абзац раз.\n\nАбзац два.",
  "price": 1790,                // гривны, базовая валюта базы
  "fairPrice": 1900,            // честная цена
  "scores": { "community": 6900000, "personal": 6200000, "ai": 5900000 },
  "class": "budget",            // budget | value | balanced | overpriced
  "connection": "wired",        // wired | wireless | hybrid
  "mechanism": "mechanical",    // mechanical | magnetic | optical | membrane
  "kolhoz": false,
  "reviews": [{ "author": "Стас", "score": 7, "date": "2026-02-15", "text": "..." }],
  "specs": { "Вес": "85 г", "Сенсор": "Mercury" },
  "shops": [{ "name": "DNS", "price": 1790 }],
  "pros": ["..."],
  "cons": ["..."],
  "life": { "months": 18, "risk": 10, "riskLabel": "...", "fail": 36, "failLabel": "..." },
  "bench": { "input": 6.0, "ergo": 8.4, "materials": 6.6, "features": 5.4,
    "reliability": 6.2, "support": 7.0, "build": 6.8, "software": 6.9,
    "value": 8.7, "feel": 6.2 }
}
```

Обязательные: `id`, `name`, `brand`, `category`, `short`, `price`,
`fairPrice`, `scores`. Остальное опционально — секции скрываются сами.

### Оценки и топы

`scores` — произвольный набор баллов в формате бенчмарков (0–10 000 000):
`community` — общество, `personal` — личная, `ai` — ИИ. Средний балл
считается по всем ключам. Топ-места ставятся автоматически: бейдж
на карточке (топ-10 категории), точное место в категории и общем зачёте —
на странице устройства.

### Теги

`kolhoz: true` — красный пульсирующий «Колхоз».
`price <= fairPrice` — «Fair deal». Оба считаются сами.

## Валюта

Цены в данных — гривны. В настройках (шестерёнка в шапке) можно выбрать
гривны, доллары, евро или рубли — всё на сайте пересчитается на лету.
Курсы прописаны в `js/data/settings.js`.

## Пагинация

30 устройств на страницу на десктопе, 15 на мобильных. Пересчитывается
при изменении размеров окна.

## Локально

Любой статик-сервер из корня, например:

```bash
python3 -m http.server 8000
```

Данные кешируются в sessionStorage на вкладку — после правок JSON
достаточно обновить страницу в новой вкладке.
